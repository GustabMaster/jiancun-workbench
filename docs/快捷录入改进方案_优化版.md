# 快捷录入改进方案（优化版）

> 目标：把「简存·单店进销存工作台」里"一笔买卖要逐个点格子"的累，降到"说一句话或敲两下"。
> 范围：纯前端功能改动，全部存本地，不碰现有数据；只有"云接口"一项需联网且可选。
> 状态：**讨论稿**，尚未开工。

---

## 一、先说清：为什么现在觉得累

一笔普通卖货，要点 6 次左右：选客户 → 选商品 → 选规格 → 填数量 → 填单价 → 点结算。
同一个人一次买好几样，这 6 下要重复好几遍；进货一张单几十个品种，就是几百下。

软件里其实**已经藏了**几样快捷手段（很多人没注意）：
- 首页四个「快捷记账」按钮
- 买卖页「复制上一条」（把上一笔带出来改改就存）
- 常用商品 / 往来会自动排前面
- 底部「智能识别」支持拍照识单、也支持手打一整句话自动拆单

下面的方案，是把这些"藏起来的"放大、再加几样真正省事的。

---

## 二、设计原则（决定先做什么）

1. **零成本、零联网、零风险 的先做**（犯错也不影响账本）。
2. **覆盖八成场景的先做**（熟客卖货、进货大单），而不是追求"全能"。
3. **"让要点的活变少"优先于"找人替我点"**——外部 App 替你点界面在技术上行不通，也不该让自动点击器碰账本。
4. **每项都可独立开关**，不强行捆绑。

## 四、分阶段详述

### 阶段 0 · 零成本零风险，立做（半天~1 天）

**P0-1 默认带出上次**
- 人话：打开买卖页，自动把"上一次的客户 / 结算方式 / 日期"选好，常见的不用再点。
- 你实际操作：打开页面 → 客户已经是老王 → 直接填货。
- 改动：打开页面时读上次记录回填；保留手动改的能力。

**P0-2 连续记账（连录）**
- 人话：同一客户买好几样，录完一件不关表单，光标停在"商品"处，直接敲下一件；全部录完点一次"结算全部"。
- 你实际操作：选老王 → 填钻头回车 → 填螺母回车 → 填扳手回车 → 点"结算全部"。
- 改动：买卖录入改为"暂存草稿 + 累加明细"，新增"结算全部"按钮；关联现金/欠款按整单一次生成。

**P0-3 一句话 / 语音录单（主入口）**
- 人话：买卖页顶部放一个大输入框"整句录入"。打 `张三 钻头5个13元 螺母3个30元` 回车 → 自动拆成：客户=张三、两行明细（钻头×5 @13、螺母×3 @30）。
  手机上用讯飞/搜狗等输入法的**语音**说同样的话 → 转成文字 → 同样拆。
- 你实际操作：对着输入框说话或打字 → 回车 → 确认明细 → 存。
- 改动：把现在藏在"智能识别"里的整句解析（`smartParseLine`，已有、且被测试覆盖）提到买卖页最显眼处，并做输入界面。
- 说明：这就是"语音记账"的正路——**识别交给手机输入法**（五金词也认得准），不靠浏览器内置语音（中文五金词易错）。

### 阶段 1 · 小成本，复用（1~2 天）

**P1-1 整单模板**
- 人话：把"客户 + 若干商品 + 数量"存成模板（命名如"老王的常备单"），下次点模板名整单带出，改数量就卖。
- 你实际操作：录好一笔 → 点"存为模板"取名 → 以后首页/买卖页点该模板。
- 改动：新增 `orderTpl` 数组（localStorage）；买卖页加"从模板新建"。

**P1-2 历史单据克隆**
- 人话：选一笔过去的买卖 → "复制为新建" → 改数量再存。比模板更随手，不用提前存。
- 你实际操作：买卖列表里点某笔 → "复制为新建" → 改 → 存。
- 改动：买卖列表行加"克隆"动作，复用提交逻辑。

**P1-3 最近成交价记忆**
- 人话：选了商品+客户后，单价自动带出上次的成交价；不对再改。
- 你实际操作：选完商品，单价已填好。
- 改动：提交时记 `lastPrice[商品id+客户id]`；打开录入时查表回填。

**P1-4 商品即录即建**
- 人话：录入时商品下拉里打一个没见过的名字，回车即新建该商品（弹个小框补单位/规格即可），不用先去"加商品"页建。
- 你实际操作：商品框打"新螺丝" → 回车 → 补一下单位 → 继续录。
- 改动：商品下拉支持"不存在则新建"分支。

### 阶段 2 · 中成本，批量 / 硬件（2~3 天）

**P2-1 进货速录**
- 人话：单独"进货多行"界面，一屏只填"名称 + 数量 + 进价"多行，填完一次落库存 + 生成应付。
- 你实际操作：切到进货速录 → 逐行填 → 提交。
- 改动：新增多行录入界面 + 批量落库（复用 `commitFlow` 进货分支）。

**P2-2 商品编号 + 扫码**
- 人话：每样货给个短编号（如 G0101）；输入框打编号或拿扫码枪扫一下即选中，光标自动跳到数量。扫码枪 = 插上就当键盘用，约 50~150 元。
- 你实际操作：商品框扫一下条码 → 光标已在数量 → 填数 → 回车。
- 改动：商品加 `code` 字段；录入支持按编号/条码定位。

**P2-3 商品批量导入**
- 人话：从 Excel 复制几行（名称/规格/单位/进价）粘贴进"批量加商品"框 → 批量建档。
- 你实际操作：Excel 里框选几行 → 复制 → 粘贴进框 → 确认。
- 改动：新增"批量加商品"解析（复用 `smartParseLine` 思路）。

### 阶段 3 · 可选，联网，智能（注册钥匙，随时可关）

**P3-1 云接口：人话 → 单据**
- 人话：设置里填一个大模型接口钥匙（DeepSeek / 通义等，按量计费，几块钱用很久）。之后说口语长句"给老王送货，钻头5盒每盒43，螺丝三包共120，先记他账上" → 交给云端理解，返回结构化单据自动落账。
- 你实际操作：设置填钥匙 → 录入框打/说长句 → 确认 → 存。
- 改动：设置加"智能接口"区；录入提交前先调用接口解析（不填钥匙则退回阶段 0 的本地规则）。
- 注意：⚠️ 要联网 + 注册钥匙 + 小额充值；**不启用完全不影响使用**。

## 六、推荐落地组合 + 预期效果

**第一优先（一次都做，零成本零风险）：P0-1 + P0-2 + P0-3**
覆盖八成日常录入时间。熟客卖货从"每笔约 6 下"降到"说一句话或敲 2 下 + 回车"。

**第二优先（用顺了再加）：P1-1 + P1-3 + P1-4**
把"熟客常单"和"新商品随手建"也解决。

**第三优先（货多 / 量大时）：P2-1 + P2-2**
进货大单、翻 dropdown 费眼时上。

**可选：P3-1**
想要"口语长句都懂"再开，随时可关。

**预期量化（估算）：**
- 熟客卖 3 样：现在 ≈ 3×6 = 18 下；组合后 ≈ 1 句话或 3 行连录 ≈ 4~5 下。
- 进货 30 个品种：现在 ≈ 180 下；进货速录后 ≈ 30 行×2 字段 + 1 提交 ≈ 60 下，且可纯键盘流。

## 七、明确不做（劝退项）

| 方案 | 为什么不做 |
|---|---|
| 浏览器内置语音直接记账 | 中文五金名词识别差，错一笔就是错账 |
| 豆包 / DeepSeek App"替我点界面" | 这些 App 碰不到本工作台，也没有替别的软件填表的通道（技术上不存在） |
| 安卓自动点击器（Auto.js 之类） | 版本一更新就失灵，识别错一个字即错账，可靠性不配记账 |
